# PivTorg Landing

Оновлена кодова версія сайту для розміщення у GitHub з сучасним дизайном, зацикленим блоком логотипів партнерів і відправкою заявок у Telegram.

## Що вже реалізовано

- Покращений адаптивний дизайн (desktop/tablet/mobile)
- Перенесено ключовий контент із поточного сайту
- Обов'язковий зациклений блок логотипів партнерів
- 2 форми заявки на сторінці
- Відправка заявок у Telegram через `api/lead` (безпечний варіант)

## Структура

- `index.html` — сторінка
- `styles.css` — стилі
- `script.js` — логіка форми та UI
- `api/lead.js` — serverless endpoint для Telegram

## Як підключити Telegram

Важливо: для форми потрібні саме **bot token** та **chat id**.

Надані вами `app-id` та `api_hash` не є даними Telegram-бота для відправки повідомлень через Bot API.

Потрібно:

1. Створити бота через `@BotFather`
2. Отримати `TELEGRAM_BOT_TOKEN`
3. Дізнатись `TELEGRAM_CHAT_ID` (ваш чат/група)

## Деплой (рекомендовано)

### Варіант 1: GitHub + Vercel (щоб форма працювала одразу)

1. Завантажте проект у GitHub репозиторій
2. Імпортуйте репозиторій у Vercel
3. Додайте змінні середовища у Vercel:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
4. Задеплойте проект

Після цього сайт і форми працюють повністю.

### Варіант 2: GitHub Pages

Сторінка працюватиме як статичний сайт, але backend `api/lead` на GitHub Pages не виконується.
Для робочих форм у такому випадку потрібен окремий backend (Vercel/Render/Cloudflare Workers).

## Локальний запуск

Можна відкрити `index.html` напряму в браузері для перегляду верстки.

Для перевірки відправки заявок потрібен середовище з підтримкою serverless-функції (`api/lead`), наприклад Vercel.
